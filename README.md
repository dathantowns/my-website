# Dathan's Portfolio Website

A modern, dynamic portfolio website showcasing my skills and projects as a junior software developer. Features an immersive video background, smooth animations, and a responsive design.

## 🌟 Features

### ✨ **Animated Intro**

- Dramatic "DATHAN" intro animation with video background
- Slow, ominous build-up with glitch effects
- Smooth transition to main portfolio content

### 🎬 **Video Background**

- Fixed video background throughout the site
- Semi-transparent overlays for optimal text readability
- Glassmorphism effects on components

### 📱 **Responsive Design**

- Fully responsive across all device sizes
- Mobile-optimized navigation and layouts
- Touch-friendly interactions

### 🧭 **Smooth Navigation**

- Fixed header with smooth scroll navigation
- Single-page application with section-based routing
- Optimized scroll positioning for fixed header

### 🎨 **Modern UI/UX**

- Custom WDXL Lubrifont TC typography
- Glassmorphism design elements
- Hover effects and transitions
- Semi-transparent backgrounds with backdrop blur

## 🚀 Tech Stack

- **Frontend Framework**: React 18
- **Build Tool**: Vite
- **Styling**: CSS3 with modern features
- **Typography**: Google Fonts (WDXL Lubrifont TC)
- **Development**: JavaScript ES6+

## 🛠️ Development

### **Prerequisites**

- Node.js (v16 or higher)
- npm or yarn

### **Installation**

```bash
# Clone the repository
git clone https://github.com/dathantowns/my-website.git

# Navigate to project directory
cd my-website

# Install dependencies
npm install

# Start development server
npm run dev
```

### **Build for Production**

```bash
# Create production build
npm run build

# Preview production build
npm run preview
```
